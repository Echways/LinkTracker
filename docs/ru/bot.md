# Бот

[English](../en/bot.md) · [Русский](bot.md) · [Документация](README.md)

Bot — единственная часть, которую видят пользователи. Он принимает обновления Telegram, выполняет команды и диалоги и доставляет уведомления.

## Команды

| Команда | Действие |
| ------- | -------- |
| `/start` | Регистрирует чат в Scrapper и здоровается |
| `/help` | Показывает список команд |
| `/track` | Запускает диалог отслеживания |
| `/untrack <url>` | Прекращает отслеживание ссылки |
| `/list` | Показывает отслеживаемые ссылки с тегами |
| `/language` | Предлагает выбрать язык кнопками |
| `/cancel` | Отменяет текущий диалог |

Меню команд в Telegram обновляется под язык чата.

## Диалог отслеживания

`/track` — короткий конечный автомат:

1. **Ссылка.** Бот просит URL и проверяет, что он ведёт на поддерживаемый источник.
2. **Теги.** Бот просит теги через запятую, не больше десяти, дубликаты убираются. О некорректных тегах сообщается.
3. **Подтверждение.** Ссылка отправляется в Scrapper, диалог завершается.

`/cancel` выходит из диалога на любом шаге. Состояние диалога хранится в Valkey `DialogTtlSeconds`, поэтому переживает перезапуск.

## Языки

По умолчанию английский. `/language` сохраняет выбор для чата, и все тексты, ошибки и пункты меню следуют ему. Тексты лежат в resource-файлах:

| Файл | Язык |
| ---- | ---- |
| `Messages.resx` | Английский |
| `Messages.ru.resx` | Русский |

Чтобы добавить язык, добавьте файл `Messages.<culture>.resx`, значение в `BotLanguage` и кнопку в callback выбора языка.

## Уведомления

Bot читает `link.processed-updates` из Kafka и отправляет каждое сообщение в свой чат. Сообщение, не доставленное после повторов, уходит в `link.processed-updates-dlq`. Также Bot принимает обновления напрямую на `POST /updates` и по gRPC, когда Scrapper работает с транспортом `Http` или `Grpc`.

## Ошибки

Ошибки Scrapper превращаются в короткие сообщения на языке чата: чат уже зарегистрирован или не зарегистрирован, ссылка уже отслеживается, ссылка не найдена, некорректная или неподдерживаемая ссылка, Scrapper недоступен.
