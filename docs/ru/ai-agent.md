# ИИ-агент

[English](../en/ai-agent.md) · [Русский](ai-agent.md) · [Документация](README.md)

AI Agent стоит между Scrapper и Bot. Он читает `link.raw-updates`, улучшает то, что увидят пользователи, и пишет в `link.processed-updates`.

## Конвейер

```mermaid
flowchart LR
    R[сырое обновление] --> F{фильтр}
    F -- отброшено --> X[ ]
    F --> S[суммаризация]
    S --> P[приоритет]
    P --> G[группировка по чату]
    G --> O[обработанное обновление]
```

Обновления типа `SystemReport` обходят конвейер и сразу уходят на выход.

## Фильтрация

Обновление отбрасывается, если сработало любое правило:

| Правило | Настройка |
| ------- | --------- |
| Текст короче минимума | `AiAgent:Filtering:MinLength` |
| Автор в списке исключений, без учёта регистра | `AiAgent:Filtering:ExcludedAuthors` |
| Текст содержит стоп-слово, без учёта регистра | `AiAgent:Filtering:StopWords` |

## Суммаризация

Текст длиннее `AiAgent:Summarization:Threshold` отправляется в Yandex AI с инструкцией изложить его в двух-трёх предложениях на русском. Более короткий текст проходит без изменений.

Если Yandex AI вернул ошибку или пустой ответ, текст обрезается до порога, и обновление всё равно уходит. Каждый такой случай считается в `summarization_fallbacks_total` с причиной, поэтому деградация видна на дашборде.

## Приоритизация

| Приоритет | Когда |
| --------- | ----- |
| High | В тексте есть слово из `HighKeywords` |
| Low | В тексте есть слово из `LowKeywords` и нет слов из высокого списка |
| Medium | Во всех остальных случаях |

## Группировка

Для каждого чата агент копит обновления `AiAgent:Grouping:WindowMs`. Когда окно закрывается, фоновая задача сбрасывает буфер. Одиночное обновление уходит как есть. Несколько превращаются в одно нумерованное сообщение `1. [url] текст` с наивысшим приоритетом группы.

Оффсет подтверждается только после публикации буферизованного обновления, поэтому при падении буфер перечитывается, а не теряется.

## Обработка сбоев

Сырое сообщение, не обработанное за `RetryAttempts`, уходит в `link.raw-updates-dlq` с ошибкой, а чтение продолжается.
